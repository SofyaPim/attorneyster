# Attorneyster — сайт (production-сборка)

Живой сайт: [sofyapim.github.io/attorneyster](https://sofyapim.github.io/attorneyster/)

## О репозитории

Это **production-вывод сборки** лендинга Attorneyster (Vite → `dist/`).
Исходный код, E2E-тесты (Playwright) и CI находятся в другом репозитории:

> **Источник и тесты:** [SofyaPim/attorneyester_tests](https://github.com/SofyaPim/attorneyester_tests)

## Как обновляется

Прямые правки здесь не требуются — изменения вносятся в исходниках
`attorneyester_tests`, а сюда приходит уже собранный сайт.
